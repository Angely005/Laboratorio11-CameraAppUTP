# 📸 CameraApp UTP - Laboratorio Nº 11

## Descripción

Este proyecto es parte del laboratorio Nº 11 del curso **Desarrollo de Aplicaciones Móviles** en la Universidad Tecnológica del Perú. El objetivo es construir una aplicación móvil en **React Native (Expo)** que acceda a la cámara del dispositivo para capturar fotos, mostrarlas en pantalla y guardar un historial de las últimas imágenes tomadas.

La app incluye funcionalidades como:

- Solicitud de permisos de cámara
- Vista previa en tiempo real
- Captura de fotos
- Visualización de imagen capturada
- Historial de las últimas 3 fotos
- Cambio entre cámara frontal y trasera
- Activación/desactivación del flash
- Almacenamiento en AsyncStorage
- Visualización de fecha y hora de cada foto
